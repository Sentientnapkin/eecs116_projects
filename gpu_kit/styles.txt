# How the autopilot sets speed (from its source):
#  - each flight draws ONE cruise speed uniformly in [CRUISE_SPEED_MIN, CRUISE_SPEED_MAX]: the top speed on straight runs
#  - within the flight it slows for corners (near-stop on sharp ones) and while it yaws to face the new direction,
#    then speeds up again, always within MAX_ACCELERATION / MAX_JERK, so speed changes are smooth (no jumps)
#  - how fast the pace itself can change: min(PHASE_ACCELERATION, 0.35*MAX_ACCELERATION/CRUISE_SPEED_MAX, 0.25*MAX_JERK/(1.95*MAX_ACCELERATION))
#  - ROADMAP_SPACING / CONNECTION_DISTANCE: how far apart the waypoints are (longer straight runs = more time at speed)
#
# wide_*: every flight gets its own top speed anywhere in 0.3-4 m/s; they differ in how hard the drone speeds up / slows down.
